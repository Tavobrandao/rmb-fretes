# 🚚 RMB Fretes - Landing Page & Presença Digital

Landing page institucional desenvolvida para a **RMB Fretes**, empresa especializada em serviços de frete particular, entregas rápidas e pequenas mudanças em Manaus e região.

Projetada com foco em alta taxa de conversão, otimização mobile (Mobile-First) e integração direta com o WhatsApp para orçamentos rápidos.

---

## 🚀 Tecnologias Utilizadas

- **React.js** (Vite)
- **Tailwind CSS v4** (Estilização responsiva e tema Dark/Amber)
- **JavaScript (ES6+)**
- **Vercel** (Hospedagem e Deploy Contínuo)

---

## 📱 Funcionalidades

- **Layout Responsivo:** Adaptado para smartphones, tablets e desktops.
- **Chamada para Ação (CTA):** Botões estratégicos direcionando para o WhatsApp com mensagem pré-formatada.
- **Apresentação de Serviços:** Cards com lista detalhada das modalidades de transporte oferecidas.
- **Diferenciais da Marca:** Destaque para limite de carga (até 500kg), segurança e pontualidade.
